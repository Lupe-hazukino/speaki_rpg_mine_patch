# スピキ鉱山 Local Controls

ｽﾋﾟｷMMO（ｽﾋﾟｷ育成）のゲーム内ゲーム「鉱山」で利用可能な操作改善非公式MODです。
このmodは、「鉱山」のみで動作します。

以下は、主な変更点です。

- アイテム欄のテクスチャ変更
- アイテムのテクスチャ変更
- UIの改善
- キーバウンドの変更および追加

この配布版は、元ゲームのテクスチャと名称を使用します。アイテムのアイコンを元ゲームの描画データから斜め上の視点で生成し、所持品画面や操作方法を変更します。

## ダウンロード

[Releases](https://github.com/Lupe-hazukino/speaki_rpg_mine_patch/releases)から、`SpeakiMiningLocal-native-public-0.1.15.zip`をダウンロードしてください。

Chromeのデベロッパーモードで手動導入する拡張機能です。対象サイトは[スピキ育成](https://speakirpg.overture.io.kr/)です。

## 初めて導入する場合

1. ZIPを解凍します。解凍したフォルダーは、導入後も削除・移動しないでください。
2. Chromeで `chrome://extensions` を開き、「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. 解凍した中の、`manifest.json`と`README.txt`がある `SpeakiMiningLocal` フォルダーを選択します。
5. 「スピキ鉱山 Local Controls」が有効になっていることと、対象サイトへのアクセスが許可されていることを確認します。
6. ゲーム画面を再読み込みし、「鉱山」に入ります。左上に「MOD設定 [F2]」が表示されます。

他の鉱山向け表示・操作変更MODは、同時に有効にしないでください。

## 更新する場合

1. 新しいZIPを解凍し、導入時のフォルダー内を新しいファイルで置き換えます。
2. `chrome://extensions` で、この拡張機能の **↻（再読み込み）** を押します。
3. 拡張機能のバージョンを確認してから、ゲーム画面で **Ctrl＋R** を押します。

**ゲームの再読み込みだけでは、Chromeが保持する接続ルールは更新されません。** 特に0.1.15へ更新する場合は、先に拡張機能の再読み込みを行ってください。

## 操作

| 操作 | 機能 |
| --- | --- |
| F2 | MOD設定を開く・閉じる |
| M | 一人称 → 三人称（後方）→ 二人称（正面）を切り替える |
| Shift | 移動速度を通常の30％にする・端からの落下を防ぐ。一人称の視点だけ少し低くなる |
| マウスホイール | ホットバー1～9の選択を切り替える |
| ドラッグ＆ドロップ | 所持品からホットバーへ登録・ホットバーの枠どうしを入れ替える |

F2の操作変更を有効にすると、次の操作も使用できます。

| 操作 | 機能 |
| --- | --- |
| F1 | HUDの表示・非表示 |
| T | チャット入力を開く。入力中のTは文字入力に使用 |
| Esc | チャットを閉じる |
| E | リュックを開く・閉じる |
| Ctrl単独 | エモート |
| 右クリック | トロッコに乗車。ブロックの配置より乗車を優先 |
| Shift | トロッコから降車 |
| 右クリック長押し | 配置できる場所に約0.2秒ごとにブロックを配置 |

## 表示言語

ゲーム設定で選択した日本語・韓国語・英語・簡体字中国語・繁体字中国語に対応します。中央に表示するアイテム名と形状名は、ゲーム本体の各言語の名称を使用します。

## 0.1.15について

この版は試験公開です。更新後のゲームファイルとの接続照合、5言語の名称900通り、連続配置25項目、キャラクターの読み込みテストをローカルで実施しています。0.1.15を実際のChrome拡張機能として適用した実ゲームでの最終確認は未完了です。

## 動作しない場合

- 拡張機能のバージョンと、導入元フォルダーを確認してください。
- 拡張機能の再読み込み後、ゲームも再読み込みしてください。
- ゲーム本体が更新された場合は、MODの更新が必要になることがあります。
- 元の表示に戻すには拡張機能をオフにし、ゲームを再読み込みしてください。
- 不具合の報告には、MODのバージョン、ゲームの表示言語、再現手順を添えてください。

このZIPには、ゲーム本体のJavaScript・画像・モデル・フォントを含めていません。ゲーム運営のMOD利用・配布条件は別途確認が必要です。
