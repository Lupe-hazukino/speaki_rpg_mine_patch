# Speaki_rpg_mine_patch（スピキクラフトMOD）

ｽﾋﾟｷMMO（ｽﾋﾟｷ育成）のゲーム内ゲーム「鉱山」で利用可能な操作改善非公式MODです。
このmodは、「鉱山」のみで動作します。
開発者(GMDT）様より、許可をいただいております。

## 主な変更点

- アイテム欄のテクスチャ変更
- アイテムのテクスチャ変更
- UIの改善
- キーバインドの変更および追加

## ダウンロード

[ダウンロードページ](https://github.com/Lupe-hazukino/speaki_rpg_mine_patch/releases/tag/v1.0)の「Assets」から、`Speaki_rpg_mine_patch-1.0.zip`（最新版）をダウンロードしてください。

対象サイトは[スピキ育成](https://speakirpg.overture.io.kr/)です。
ゲームのアップデートにより、使用できなくなることがあります。その場合は、随時更新します。
お手数ですが、再度このページよりダウンロード、再適用してください。

## 導入方法

1. ZIPを解凍します。導入後も、解凍したフォルダーは削除・移動しないでください。
2. Chromeで `chrome://extensions` を開き、「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. `manifest.json`と`README.txt`が入っている「Speaki_rpg_mine_patch」フォルダーを選びます。
5. 「Speaki_rpg_mine_patch（スピキクラフトMOD）」を有効にし、対象サイトへのアクセスを許可します。
6. ゲームを再読み込みし、「鉱山」に入ります。左上の「MOD設定 [F2]」から設定できます。

他の鉱山向け表示・操作変更MODは、同時に有効にしないでください。

## 操作方法

| 操作 | 機能 |
| --- | --- |
| F2 | MOD設定を開く・閉じる |
| M | 一人称 → 三人称（後方）→ 二人称（正面）を切り替える |
| Shift | 移動速度を下げ、ブロックの端からの落下を防ぐ。一人称の視点が少し低くなります。F2の設定で切り替えられます |
| マウスホイール | ホットバー1～9の選択を切り替える |
| ドラッグ＆ドロップ | 所持品からホットバーへ登録する。ホットバーの枠どうしでは内容を入れ替える |

F2の「某ゲーム風の操作」をオンにすると、次の操作を使えます。

| 操作 | 機能 |
| --- | --- |
| F1 | HUDの表示・非表示 |
| T | チャットを開いて文字を入力する。入力中のTは文字入力に使用します |
| Esc | チャットを閉じる |
| E | リュックを開く・閉じる |
| Ctrl単独 | エモート。動作は二人称・三人称で表示します |
| Shift（乗車中） | トロッコから降りる |

## 表示設定

F2から次の設定を変更できます。

| 設定 | 内容 |
| --- | --- |
| 写実的な光 | 柔らかい光を追加して、リアルな描写にする。「影を表示する」よりも負荷が高くなる |
| 影を表示する | 簡易的な影を表示する |
| 時間帯 | 朝・昼・夕方から選択する。初期選択は昼 |
| 影の範囲 | 小：32ブロック、中：64ブロック、高：128ブロック、極高：表示中すべて。初期選択は極高 |

「写実的な光」と「影を表示する」はどちらか一方を選べます。切り替えるには、使用中の方を先にオフにしてください。ゲームを再読み込みすると、これらの設定は初期状態に戻ります。

## 表示言語

ゲーム設定で選択した日本語・韓国語・英語・簡体字中国語・繁体字中国語に対応します。言語を変更した後はゲームを再読み込みしてください。

## 更新方法

1. 新しいZIPを解凍し、導入先フォルダー内を新しいファイルで置き換えます。
2. `chrome://extensions` で拡張機能の **↻（再読み込み）** を押します。
3. ゲームも再読み込みします。

## 解除方法

Chromeで拡張機能をオフにし、ゲームを再読み込みします。
